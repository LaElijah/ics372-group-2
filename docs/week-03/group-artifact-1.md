## What We're Not Sure About
Somethings we aren't sure about are requirement 2.7 and 3.4. This is because requirement 2.7 says a customer should be able to fix their order after they placed it, but 3.4 says that an order shouldn't be able to be changed after its been placed. This is a conflict between the two requirements which makes you wonder which one takes priority over the other. There was another conflict between requirement 3.7 and 4.1 which revolved around modifying menu items. In requirement 3.7 it talked about allowing baristas to be able to change the menu while 4.1 says only managers can change the menu. These contradict each other and makes you ask whether a barista can actually add items or what are the permissions given to employees when it comes to adding items. Another thing we aren't sure about is that some non functional requirements tend to prompt functional requirements which raises questions on how to approach that problem.
